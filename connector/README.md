# SAP Desk 本机连接助手 · Mac 免安装试用版

本包为当前 Mac 的 DS4/110 验证原型，解压后运行，不安装系统服务、不添加开机项。
它复用这台 Mac 已有的 Node.js、SAP 万能工具箱、sap-eyes、node-rfc、SAP RFC SDK 和工具箱加密凭据。
**不是可在任意新电脑上直接运行的独立二进制，暂不包含 Windows 适配。**

## 开始使用

1. 打开本地 SAP Desk 预览 `http://127.0.0.1:5175/#/assistant`，使用本地测试账号登录。
2. 点击「管理连接与查询」→「生成一次性配对码」。
3. 双击 `启动连接器.command`。如果终端已配置 Node，也可以执行 `node connector.mjs`。
4. 服务器地址直接回车使用本地预览地址，再粘贴一次性配对码。
5. 回网页提交查询：事务码映射 `SE38`，或 DDIC 结构 `T000`。
6. 终端会显示本次对象及结果接收地址。输入 `y` 读取并回传；其他输入拒绝。
7. 网页查看真实结果。选择「附到下一条提问」才会将这份快照加入问题。

配对码 10 分钟有效、只能使用一次；新码使旧码失效。设备授权最长 24 小时，密钥只在当前进程内存中。
每次重新启动需重新配对。网页「断开」会撤销设备并终止未完成任务；关闭终端后约 45 秒显示离线。
查询确认等待最多 90 秒，SAP 调用最长 70 秒，队列整体最多 4 分钟；失败不会自动重做 SAP 查询。

## 范围与限制

- 仅固定 DS4/110，实际 SAP 身份和 endpoint 由现有 sap-eyes 双重校验。
- 仅事务码映射、DDIC 元数据，名称限定 A-Z、0-9、下划线；不支持命名空间对象、源码、业务表记录、SAP 写入或 QS4/PS4。
- 每个账号只可查看自己的设备和结果；每台设备同时仅一个查询，每人每天最多 100 次。
- 凭据始终由本机工具箱按现有匿名管道方式提供；本包不包含或导出 SAP 密码，SAP 用户名在回传前移除。
- 结果最多 96 KiB。结果含数据来源标记，始终是不可信材料，不是可执行指令。
- 本机终端逐条确认只读范围和接收服务器。不要将配对码输入不认识的程序。
- 首轮使用本地预览，结果只回传此 Mac。把快照附到启用的 AI 提问后，快照会发送给配置的模型服务；本次只验证已授权的 SE38 元数据。
- 关闭终端不会卸载任何东西，因为没有安装服务。可删除解压文件；服务器中的历史查询仍由账号管理。
- 当前在线 SAP Desk 尚未发布连接器接口，不要将本原型连到线上地址。

## 运行环境故障

- Node 不存在：此原型需要已有 SAP 工具运行环境，不自动下载安装依赖。
- 未配对/设备授权失效：网页生成新码；已离线的旧设备可点「断开」。
- sap_failed：检查本机工具箱 DS4 连接及 SAP 权限。客户端不会把底层 stderr 或凭据输出到网页。
- timeout：查看是否及时在终端确认、内网是否可用；排除后重新提交。
- macOS 若阻止启动：先核对来源；可在已经使用 Node 的终端运行 `node connector.mjs`，不需要关闭系统安全功能。
