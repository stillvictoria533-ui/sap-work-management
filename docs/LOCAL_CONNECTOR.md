# 本机 DS4 连接器原型（待发布）

## 决策记录 · 2026-10-14

需求：顾问使用自己的电脑访问 SAP，先在当前 Mac 免安装验证 DS4，不依赖常驻 Windows。
决定：账号会话创建一次性配对码；Node 连接器主动通过 HTTP(S) 领取绑定设备的结构化任务，固定调用现有 sap-eyes，逐次确认后回传结果；用户主动选择结果附加到聊天。模型不能发起工具调用。
取舍：复用已有 Mac 环境能验证真实权限、身份和 RFC 路径，但本包不是通用安装包；初版只允许事务码映射和 DDIC，不承诺任意顾问电脑即开即用或全天候在线。以显式查询验证边界，再扩展自然语言任务规划。

## 本地启用

`SAP_CONNECTOR_ENABLED=true`（默认 false）启用接口和页面入口；迁移 assistant/0003。
SQLite 本地预览使用 IMMEDIATE 事务，避免并发心跳/领取任务的读锁升级冲突；生产 PostgreSQL 使用行锁。
使用独立 SQLite 数据库 `.local-connector-preview.sqlite3`，不改线上数据库。
后端回环端口 8016，前端端口 5175，Vite 代理 `/api` 到后端。
连接器源文件位于 `connector/`，打包脚本 `scripts/package_connector.py`。
免安装 zip 仅包含连接器、启动脚本、README，不包含任何本机凭据、SAP 工具箱、SDK 或真实查询结果。

## 协议与授权

- 浏览器接口使用现有登录、账号版本和 CSRF 校验；每个账号最多 3 台有效设备。
- 配对码 192 bit 随机值，10 分钟有效、原子消费、只保存 SHA256；设备 token 256 bit，24 小时，服务端只存哈希，客户端只存内存。
- 设备 token 仅可 heartbeat/claim/complete；不可创建查询、访问聊天或其他设备的任务。账号禁用、密码重置、设备撤销均使后续请求失效。
- 任务绑定账号/设备/idempotency key；领取一次，不自动重放；结果必须包含一次性 lease，结束后不能覆盖。
- 任务 4 分钟过期；进程确认 90 秒、执行 70 秒；45 秒无 heartbeat 显示离线。heartbeat 仅说明连接器在线，SAP 最近读取成功单独标记。
- 请求仅两个枚举操作和精确对象名称；连接器再次做严格字段、系统、期限校验。固定二进制、脚本路径和 `--conn DS4`，不执行 shell，不接受远程 endpoint、任意 argv、源码或写入请求。
- 设备撤销后服务器拒绝结果，客户端下次 heartbeat 中断本地子进程。它不能撤回 SAP 已执行的只读请求；同时发生的撤销可能在下一次心跳前仍有在途读取。
- 每账号每天 100 个查询，单设备一个活跃任务，单结果 96 KiB。真实查询内容只保存到该账号的查询记录；审计只写操作、对象、状态和引用。

## 证据与 AI

连接器使用现有 sap-eyes envelope 的 SID/client/object/operation 双端检查。该 envelope 不是 SAP 签名或不可变远程认证；已配对的本机程序仍在信任边界内。同一 Mac 用户能够修改程序或访问自身 SAP 凭据，这个原型不抵抗本机用户恶意进程。
用户主动附加 30 分钟内成功结果后，查询外键锁定到该问题；模型可引用历史快照，不得推断实时状态、执行工具或提升证据为指令。SAP 用户名在连接器回传前移除，模型上下文再次移除，兼容较早的本地测试记录。
设备离线时可查看历史结果；已撤销设备的结果不可新增到提问。结果既已附到历史问题，则作为历史材料保留。
模型运行仍使用原有受限 Codex 适配器；未启动 worker 不会自动调用外部 AI。

## 本次验证结果

2026-10-14 本机实际联通 DS4/110：
- SE38 返回程序 RSABAPPROGRAM、屏幕 1000、描述“ABAP 编辑器”。
- T000 DDIC 返回 17 个字段的元数据，未读取 T000 业务记录。
- 网页提交 → 本机逐条同意 → sap-eyes 双重身份校验 → 结果回传 → 用户选择附加 → Codex 分析成功。
- 外部模型只调用一次，仅发送用户明确批准的 SE38 快照，已检查无 SAP 用户名、密码、业务记录或关联工单。T000 结果未交给外部模型。
- 拒绝查询不执行 SAP；在终端待确认时网页撤销设备，客户端中断，查询记录为 revoked。
- SQLite 并发回环检查：修复前 32 次有 15 次锁冲突，改用 IMMEDIATE 后 32 次全部 HTTP 200；检查未调用 SAP。
- 后端 61 项、前端 8 项、连接器 5 项、部署/运维 21 项测试通过；前端类型检查/构建通过。
- 最终适配器对已采集两份真实证据完成哈希复核并移除 SAP 用户名，无重复 SAP 调用。
- 启动脚本按 Finder 的精简 PATH 验证，能发现当前用户已有 Node.js。zip 白名单与 CRC 检查通过。

本地 AI 使用单次 worker 验证后退出，没有运行持续分析服务。预览中保留真实查询与已完成回答。测试设备已撤销，用户可用试用包重新配对。
本地预览登录账号保存在项目 `.local-connector-credentials.json`（0600，本机专用，不含线上或 SAP 账号）。

| --- | --- | --- |
| sap-eyes-mac | tcode / ddic | 上文 DS4 实机成功 |
| sap-gui-windows | gui_session，固定 CURRENT | 协议及静态检查通过，Windows COM 待实测 |

Windows 只读取当前已登录会话的事务码、程序、屏幕；不操作控件或导航，不等价于任意事务码/DDIC查询。
只接受唯一 DS4/110 登录会话，固定系统编号00、应用服务器解析到10.2.22.34，页面发生变化即拒绝。
GUI 身份检查来自本地 GUI 信息，不是 RFC_SYSTEM_INFO 双重验证。负载均衡/32位GUI/脚本策略需按实机反馈适配，不能降低现有身份或脚本安全设置。
脚本等待和 COM 读取在可中断的独立 PowerShell 子进程中执行；最多60秒，撤销后下一心跳结束子进程，不关闭SAP GUI。
结果仅 program/screen/source/transaction 及证据标记；服务器拒绝额外画面内容、用户名、密码或不匹配hash。

交付 `release/SAPDesk-Connector-Windows-Pilot.zip`：先运行 `Check-DS4.cmd`，离线输出只读快照，不上传任何数据。
`Start-Connector.cmd` 提供配对与回传，但当前线上接口未发布，Mac回环地址不能从Windows访问，需先准备可信HTTPS测试入口或获准发布。
本轮验证：assistant 33项、前端8项、部署/静态边界24项通过；前端类型检查和构建通过。没有Windows执行环境，未宣称PowerShell/COM实机测试通过。
