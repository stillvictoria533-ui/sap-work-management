# 四状态工单流程

待受理 → 处理中 → 待验收 → 已完成。已完成即归档。

- 管理员：开始处理、提交验收；也可填写原因直接完成。
- 顾问：自己的待验收工单可确认完成或填写问题退回处理。
- 管理员与工单所属顾问：可填写原因重新打开已完成工单。
- 回复只产生回复记录与提醒，不改变状态；已完成工单重新打开后才能回复。
- 状态操作使用独立 POST /api/tickets/:id/status 接口，包含 action、version、reason。
- 所有写入使用行锁与版本校验；每次状态操作形成一条带操作人、时间与说明的时间线记录，并触发站内提醒与钉钉队列。
- 升级迁移将 closed 转为 done，历史事件原样保留，追加系统迁移记录，不发送迁移通知。原待确认显示为待验收。
- 旧页面携带 status 的回复请求会被拒绝并提示刷新，避免意外变更。
