# 工单标签数量修复 · 待发布审阅

2026-10-21，已完成本地修复，尚未发布。

根因：页面顶部“全部／进行中／未读更新”使用全局 `/stats`，实际列表使用当前范围和筛选，导致“需要我处理”列表为 6 条而标签显示全站 18／7。

修复后，列表接口附带 `tab_counts`，按当前登录用户权限、页面范围、搜索、模块、状态、优先级、提交人和排期条件统计。标签数量覆盖所有分页，不受当前选中标签影响；切换条件或请求失败时显示“—”，不沿用上一条件的数量。侧栏全局数量继续保留。

“进行中”保留原有未完成口径（待受理、处理中、待验收），没有改成仅“处理中”。
