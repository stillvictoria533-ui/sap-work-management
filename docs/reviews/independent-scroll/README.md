## 最终效果

- 桌面工作台适配当前窗口高度，右侧内容独立滚动，左侧不随工单列表移动。
- “返回首页”和用户信息保持在左侧可视区域底部，无需滚到工单列表末尾。
- 窗口较矮时，只滚动左侧导航菜单，品牌和底部信息保持可见。
- 手机端（宽度不超过 650px）保留原有顶部导航和整页滚动。
- 切换页面或工单分区回到顶部；筛选操作不强制回顶；浏览器返回可恢复右侧位置，并等待异步列表加载。
