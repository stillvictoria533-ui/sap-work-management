# 工单列表筛选精简 · 本地审阅

已完成用户指定的四项调整，尚未发布。截图来自独立本地测试库，均为虚构样例。

## 最终效果

- 默认仅显示搜索、模块、状态和“更多筛选”。优先级、提交人、开发排期、排序、只看未读统一放进折叠区。展开状态随列表及详情返回保留。
- 非默认的已选条件显示在列表上方，折叠区收起后仍可见。可单独移除，或一键清除；移除条件后回到第一页，保持当前工单范围。搜索、排序条件同样明确展示。
- “更多筛选”旁的数字表示折叠区中生效的条件数量。
- “需要我处理”的状态选项移除“已完成”；“已归档”隐藏状态筛选、每行重复的状态列及不适用的排期筛选，预计日期列仍保留供查阅。
- 旧链接中不适用于当前范围的状态／排期条件不进入请求，并回到第一页，防止隐藏条件造成空列表。
- 只有一页或零结果时，仅显示“共 X 条”；超过 20 条才显示分页按钮与页码。

这次不改列头排序方式、不删除其他导航入口，不改后端业务规则。

## 验证

前端 19 项测试通过，TypeScript 检查及 Vite 构建通过。
