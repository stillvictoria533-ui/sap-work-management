# 开发日历数据隔离专项复核

2026-10-23 13:51（北京时间）完成。结论：本次覆盖的月份、日期、分页和网址参数操作均未发现越权，未修改线上运行代码。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 切换月份、日期及默认选中日期 | 工单明细、提交时间、计划日期和统计均只属于当前顾问 |
| 正常分页、末页、跟随下一页链接 | 独立测试数据的 3 页结果均限定为本人；不会拼入其他人的工单 |
| 越界、负数、无效页码 | 返回 404，不返回工单结果 |
| 伪造 owner、owner_id、user_id、owner__id | 不能改变实际登录顾问的数据范围 |
| 伪造 role=admin、is_admin、is_staff、is_superuser、scope=all | 不能提升日历权限 |
| 放大 page_size、limit 或修改 offset | 不能扩大数据范围或越过后端分页 |
| 重复月份、owner、role、page 参数 | 按服务端实际解析结果处理，仍保持本人范围 |
| 非法月份、日期、模式或跨月日期 | 返回 400，不返回工单结果 |
| 从日历伪造他人工单详情网址 | 返回 404 |
| 月度、每日、紧急数量及全部月份待评估数量 | 均与本人记录独立核算结果一致 |
