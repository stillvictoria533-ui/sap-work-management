## 修改内容

- 源码类型允许从原始受理材料中与对象紧邻的明确类型文字识别，兼容类型在名称前、名称后的写法；名称重叠、跨行及相邻对象不会互相继承类型。旧范围只有在原始材料摘要、受理事件和系统匹配且限制可解释时，才恢复当时已明确的类型；接口命名本身不作为类型证明。
- 对原范围中未明确类型的对象，新增仅供可信运维、且必须有用户明确继续请求的受控入口。它在原 DS4/QS4 对象范围内检查新鲜、精确且唯一的公司目录结果；PS4 不启用该目录搜索，模型和自动网关不能调用该入口。内容摘要不是签名，运维调用者仍必须独立核验公司工具的实际身份与证据来源。
- 该入口只接受尚在处理、受理有效、版本一致、已终止且没有 SAP 查询预留的旧轮次。新建独立轮次和系统时间线事件，保留旧次数、期限、查询记录与审计；重复请求幂等，不发送额外通知。新轮次仍遵循原查询预算、租约、版本、人工抢先和证据回执门禁。
- 工单详情展示最近受阻类别；明确缺少对象类型时立即转人工，避免重复无效尝试；超时后仍可显示原始受阻类别。新诊断细分使用固定白名单，不记录原始模型输出或异常文本。历史只有笼统错误码的记录仍如实显示笼统类别。
